## 1. Mission

Make the map self-explanatory: danger zones styled by severity, an on-map legend, richer
zone/route popups (name, severity, reason, and "what the reroute saves you"), clearer
route hierarchy (direct vs reroute), and small usability wins (scale bar, hover
highlight) — all inside the existing vanilla-Leaflet component.

## 2. Context — what exists today

`src/components/MapView.tsx` (116 lines), vanilla Leaflet (no react-leaflet — keep it):

- Map init once (`:25-43`): OSM raster tiles, `worldCopyJump: true`, view `[32,35]@3`,
  one `LayerGroup` for everything (`:35`), cleanup on unmount.
- Zones (`:52-61`): **every zone is drawn identically red** (`#ef4444`, fill 0.15) with a
  sticky tooltip `${z.name} — ${z.reason}` — `severity` (`"avoid" | "caution"`,
  `types.ts:15`) is **ignored**, even though the type supports it.
- Routes (`:64-86`): direct path red-dashed when crossing / blue otherwise; reroute green
  weight-4; tooltips are static one-liners. Origin/destination circleMarkers (`:88-105`),
  green/red fill. `fitBounds` over direct+avoid (`:107-110`).
- The **legend lives in the sidebar as text** (`page.tsx:264-269`, hardcoded colored
  glyphs) — it should live on the map (and the sidebar copy can then go).
- `RouteResult` gives the popup everything it needs: `intersectedZones[].{name,severity,
  reason}`, `directDistanceKm`, `avoidanceDistanceKm`, `addedKm` (`types.ts:33-44`).
- CSS: `.map-pane > div { position:absolute; inset:0 }` (`globals.css:43`) sizes the map;
  Leaflet's own CSS is imported in the component (`:5`).

## 3. Non-goals

- No tile-provider change (OSM raster stays — key-free is a product feature), no vector
  tiles, no clustering, no animation libraries.
- No react-leaflet migration.
- No new data on the map (e.g. airports/waypoint markers) beyond what `RouteResult`
  already carries.
- No mobile gesture work (P5.1 owns responsive behavior; the map already fills its pane).

## 4. Design decisions (pre-made)

1. **Severity styling** (single source of truth — export a `ZONE_STYLE` map so the legend
   reuses it):
   | severity | stroke | fill | fillOpacity | dash |
   |---|---|---|---|---|
   | `avoid` | `#ef4444` | `#ef4444` | 0.18 | none |
   | `caution` | `#f59e0b` | `#f59e0b` | 0.12 | `4 4` |
2. **Legend as a Leaflet control** (`L.Control` subclass, bottom-left): rows for avoid
   zone, caution zone, direct path, direct-crossing path, reroute, origin, destination.
   Built from `ZONE_STYLE` + the route colors (lift those into a `ROUTE_STYLE` const
   too — `#3b82f6` / `#ef4444` dashed / `#22c55e`). Plain DOM in `onAdd` (no React
   portal needed), styled via appended `globals.css` classes (`.map-legend`, dark card
   look consistent with the sidebar). Once it exists, delete the sidebar text legend in
   `page.tsx:264-269`.
3. **Popups over tooltips for zones**: keep the sticky hover tooltip (name only), add a
   click **popup**: severity chip (colored), zone name, full `reason`, and the standing
   disclaimer line "Approximate boundary — not for operational use" (G4(a) on the map
   itself). Popups are small HTML strings — build with a helper, escape nothing
   user-generated (zone data is repo-controlled; still use `textContent`-style building
   to stay safe).
4. **Route popups**: direct path popup shows `directDistanceKm` + crossed-zone names;
   reroute popup shows `avoidanceDistanceKm` and `+addedKm km vs direct`. Data is already
   in props — no fetches.
5. **Hover emphasis**: `mouseover` on a polyline bumps `weight` +2 and `opacity` to 1;
   `mouseout` restores. Same for zone fillOpacity (+0.08). Pure Leaflet events, ~10 lines.
6. **Z-ordering**: draw zones first (existing order is fine), but give the reroute a
   dedicated `pane` (`map.createPane("routes")`, zIndex 450) so green stays above zone
   fills at every zoom (today it relies on insertion order within one LayerGroup — works,
   but panes make it explicit and survive refactors).
7. **Scale control**: `L.control.scale({ imperial: false })` bottom-right. Cheap, useful
   for "how big is this detour really".
8. **Keep `aria-label="Route map"`** on the container (`:114`) and add
   `role="region"` — P5.1 handles broader a11y; legend text doubles as the accessible
   description of the color coding (give the legend `aria-hidden="false"` and real text).

## 8. Edge cases & failure modes

- **Repeated redraws leaking event handlers**: handlers attach to layers that get
  `clearLayers()`d — Leaflet drops them with the layer; verify no accumulation via the
  re-plan ×3 check.
- **Popup HTML and future user data**: zone data is repo-controlled today, but P1.4's
  ingested names come from external datasets — building popups via `createElement` +
  `textContent` (not innerHTML interpolation) makes that a non-issue permanently.
- **`worldCopyJump` + popups**: popups on wrapped copies can open on the far copy —
  acceptable quirk; don't chase it.
- **Legend on tiny embedded maps** (none exist today) — CSS hides ≤480px per AC.
- **Color-blind users**: dash patterns (caution dashed, crossing dashed) carry the signal
  redundantly with color — keep dashes when tuning styles.
