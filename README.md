# TravelScout

A simple web app that maps flight routes between two locations while **avoiding dangerous airspace**
(default focus: Iran / configurable conflict zones), surfaces flight options, checks flight status, and
uses the Claude API (web search) to report live geopolitical "heat" and airline cancellations for a region.
